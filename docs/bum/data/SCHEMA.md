# БУМ – формат на данните

Всеки човек е един обект. Файловете са: `ten.js` (10 БУМа), `sto-a.js` … `sto-e.js` (СтоБУМ), `kilo.js` (КилоБУМ),
`facets.js` (сфери и къде живее), `ka.js` (уроци от Кан Академия), `admin.enc.js` (шифрован, само за admin.html).
Файловете на СтоБУМ започват така:

```js
window.BUM_STO = (window.BUM_STO || []).concat([
  { ... }, { ... }
]);
```

## Полета

| поле | тип | бележка |
|---|---|---|
| `id` | string | латиница, малки букви, тирета: `lyubomir-chakalov`. Уникално. |
| `name` | string | „Любомир Чакалов“ |
| `sex` | `'m'` / `'f'` | |
| `born` | number | година на раждане (за приблизителна: най-добрата оценка, и `bornApprox: true`) |
| `died` | number / null | `null` ако е жив/жива |
| `place` | string | място на раждане, кратко: „Самоков“, „Виена, Австрия“ |
| `field` | string | основната сфера, един от: `math`, `cs`, `physics`, `astro`, `chem`, `bio`, `med`, `eng`, `econ`, `games`, `edu`, `earth` (`business` се ползва само като допълнителна сфера в `facets.js`) |
| `motif` | string | картинка, свързана с работата, един от: `curve` (графика на функция), `polynomial` (корени в комплексната равнина), `graph` (мрежа от върхове), `binary` (битове), `circuit` (схема/чип), `wave` (вълни), `atom`, `crystal` (кристална решетка), `molecule` (шестоъгълни пръстени), `orbit` (планета и траектория), `stars` (съзвездие/телескоп), `dna`, `cell` (клетки/бактерии), `heart` (ЕКГ), `chart` (стълбчета и линия), `gear` (зъбни колела), `bridge` (арка/мост), `chess`, `plane` (самолет/полет), `book` (книга/учебник), `leaf` (растение), `neural` (невронна мрежа/език) |
| `title` | string | заглавие на историята, до ~70 знака, звучно, без кликбейт: „Човекът, който научи България да смята с компютри“ |
| `lede` | string | едно изречение (до ~200 знака) – същността на приноса |
| `story` | string[] | 2–3 абзаца, общо 120–220 думи (в „10 БУМа“ – 3–4 абзаца). Ясен, жив език за ученици 12–18 г. и възрастни. Конкретни факти (години, места, какво точно е направено, защо е важно). Без измислени подробности. |
| `num` | `{n, t}` | „БУМ число“: голямо число/година и кратко обяснение. `{ n: '1938', t: 'годината, в която описват новия начин на растеж на кристалите' }` |
| `links` | `{t, u}[]` | 1–3 линка за повече информация. `t` – кратък надпис („Уикипедия“, „Уикипедия (англ.)“, „БАН“, …). САМО адреси, които сте видели в резултатите от търсене. |
| `wiki` | `{bg?, en?}` | точните заглавия на статиите в Уикипедия (както са в адреса, с интервали вместо `_`), за да се вземе снимка. Пропуснете език, за който няма статия. |
| `tags` | string[] | 1–3 кратки етикета: „кристали“, „олимпиади“, „ДНК“ |

## Допълнителни полета (незадължителни)

| поле | къде | бележка |
|---|---|---|
| `bornApprox` | всички | годината на раждане е приблизителна; за живите се показва „съвременник/съвременничка“ |
| `bornLabel` | всички | текст вместо годините, напр. „ЕЛКА · 1965“ |
| `diedApprox` | всички | годината на смъртта е приблизителна |
| `noPhoto` | всички | `true` – не се търси снимка в Уикипедия (напр. когато главната снимка е паметник или плоча) |
| `photoFile` | всички | ръчно избран файл от Уикимедия Общомедия, напр. `'Ivan Stranski.jpg'`; има предимство пред всичко останало |
| `wikidata` | всички | Q-ID в Уикидата (напр. `'Q123'`); оттам се взима изображението (P18), ако няма снимка в Уикипедия |
| `photoUrl`, `photoSource` | всички | снимка от друг сайт и страницата, откъдето е; под нея пише „Лицензионните права още се проверяват“ |
| `art` | `ten.js` | ръчно нарисувана графика от `js/art.js` |
| `fictional` | `kilo.js` | `true` за измислен човек – сайтът показва ясен знак |
| `avatar` | `kilo.js` | параметри за нарисуван портрет (вместо снимка) |
| `work` | `kilo.js` | `{ motif, caption }` – картинка от работата |
| `video` | `kilo.js` | `{ src, poster, caption }` – вертикално видео 9:16 |
| `interview` | `kilo.js` | `[{ q, a }]` – 2–4 въпроса |

## `facets.js`

`{ '<id>': { s: ['cs', 'business'], lv: 'bg' | 'abroad' | 'both' } }` – всички сфери (първата е основната) и къде живее или е живял/а основно. Градът на раждане се извежда от `place`.

## `ka.js`

`{ '<id>' или '@home' | '@ten' | '@sto' | '@kilo' | '@stats' | '@karta' | '@about': [{ t, c, u }] }` – 1–2 урока; адресите са само от индекса на bg.khanacademy.org.

## ka-topics.js – теми на уроците от Кан Академия

`window.BUM_KA_TOPICS = { topics: [{ k, t }], map: { '<адрес без https://bg.khanacademy.org/math/>': k } }`.
Страница „Статистика“ показва най-долу всички уроци от `ka.js`, групирани по тези теми, с брой споменавания и хората.
Нов урок, който не е в `map`, отива в група „Други“ – добави го в `map`, за да влезе в правилната тема.
