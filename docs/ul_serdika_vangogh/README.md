# ул. „Сердика“ 20 по Ван Гог

Втора версия на [разходката около ул. „Сердика“ 20](../ul_serdika/): същите улици и
сгради от OpenStreetMap в радиус 200 м, но нарисувани с маслени бои в стила на
Винсент ван Гог.

## Как е нарисувано

| Какво | Как |
| --- | --- |
| Мазки по всичко | Всички текстури (фасади, прозорци, капаци, павета, плочки, керемиди, трева, листа, кора, табели) са нарисувани с код от отделни мазки с релеф — `js/paint.js` |
| Маслени бои | Картината минава през филтър на Кувахара, който превръща детайла в петна боя |
| Контури | Ръбовете на сградите и предметите стават прекъснати линии в ултрамарин |
| Цветове | По-наситени; сенките отиват към синьо-виолетово, светлината — към хромово жълто; отгоре е тъканта на платното |
| Накривени стени | Стените, покривите, фенерите и стволовете се огъват и накланят нагоре, както къщите в Овер (шейдър `vgWobble`) |
| Небе | Мазките следват вихри като в „Звездна нощ“ (1889); слънцето е с кръгове като в „Сеячът“ |
| Нощ | След залез небето става звездно с полумесец, прозорците светват, фенерите имат ореоли и златни петна по паважа |
| Кафенета | При 50 кафенета и ресторанта от картата има жълти тенти, масички и столчета — поклон към „Тераса на кафене нощем“ (Арл, 1888) |
| Дървета | Туфи от мазки в зелено, жълто и оранжево според сезона; всяко шесто дърво е кипарис като пламък |
| Без кубчета | Няма коли, кутии и светофари; пейките, масите, комините и фенерите са заоблени |

Данните, кодът за OpenStreetMap и three.js са общи с истинската версия:
`../ul_serdika/data/osm.json`, `../ul_serdika/js/osm.js`, `../ul_serdika/js/three.module.min.js`.

## Файлове

| Файл | Какво прави |
| --- | --- |
| `index.html` | страница и интерфейс |
| `js/main.js` | сцена, вихрено небе, филтър „маслени бои“, нощ, управление, карта |
| `js/world.js` | сгради, улици, табели, дървета, фенери, кафенета (по `../ul_serdika/js/world.js`) |
| `js/paint.js` | всички текстури с мазки, ръкописните табели и накривяването |

Управлението е същото: W A S D / стрелки, мишка, Shift, M — карта, H — обратно пред №20.
