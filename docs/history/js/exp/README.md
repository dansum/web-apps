# 3D преживявания на високо качество

Всяко преживяване е ES модул `js/exp/<име>.js`, който изнася:

```js
export function mount(container, { skill, course, onComplete }) {
  // ...
  return { dispose() { /* спира всичко и освобождава паметта */ } };
}
```

Умението в `data/gradeN.js` има `quality: "high"` и `experience: "<име>"`. Сайтът зарежда модула и вика `mount`.
Образци: `foodchain.js` (най-новият, с разходки и меню), `cell.js`, `lever.js`.

## Инструменти (`js/kit.js`, `js/exp/shell.js`)

| Функция | За какво е |
|---|---|
| `createShell(container, { steps })` | Рамка: 3D сцена вляво, панел със задачата вдясно. `step(i)`, `task(html)`, `msg(text, 'good'/'bad')`, `score(text)`, `setControls(html)`, `finish(ratio, onComplete, restart)`. |
| `stepScore(mistakes, allowed)` | Резултат за стъпка: 1 без грешки, намалява с всяка грешка. |
| `createStage(el, opts)` | Сцена, камера, светлини, OrbitControls. `tick(fn)`, `onClick`, `onHover`, `enableDrag`, `bubble`, `flyTo`, `focusOn`, `stopFollow`, `steadyLabel`, `screenOf`. |
| `cornerMenu(stage, { title, items, onSelect })` | Меню в ъгъла на сцената, от което детето избира обект. `mark(id)` слага ✓, `setActive(id)`, `show(bool)`. |
| `labelSprite(text)` | Етикет в 3D, който винаги гледа към камерата. С `stage.steadyLabel(sprite)` пази размера си на екрана. |
| `addHitBox(group)` | Невидима по-голяма зона за клик и влачене. Задължителна за всичко малко. |
| `zoneRing(color)` | Кръг на земята, в който се пускат обекти при сортиране. |
| `mat(color, { flat })` | Материал. |

Кликаемите обекти носят `userData.pickId`; влачимите — и `userData.dragId`. Скрити обекти (`visible = false`) не се кликат.

## Стандарт за качество

1. **Четири стъпки:** опознай → направи/изследвай → приложи → предскажи или пренеси към живота. Всяка стъпка проверява очаквани резултати от `skill.mon.competences`.
2. **Опознаване с меню в ъгъла.** Първата стъпка има `cornerMenu` с всички обекти, които могат да се разгледат. Изборът води камерата до обекта (`focusOn`) и показва балонче с кратко обяснение. Разгледаните получават ✓.
3. **Сцената е жива.** Постоянно, спокойно движение: животни се разхождат, частици се движат, вода тече, облаци плуват, сърце бие. Нищо не стои напълно неподвижно, но и нищо не пречи на задачата.
4. **Текстът е на логичното място.** Обясненията са в балончета до обекта (`stage.bubble`), не в отделен блок. Панелът вдясно съдържа само задачата и кратка обратна връзка.
5. **Детето прави, а не чете.** Влачи, върти, плъзга, пуска, наблюдава резултата. Поне една стъпка е симулация, в която детето променя нещо и вижда последствието.
6. **Обратна връзка при грешка** казва защо е грешно, без да издава веднага верния отговор. След 2–3 грешки идва подсказка.
7. **Език:** правилен български за съответната възраст, кавички „…“, без английски думи. Научно вярно.
8. **Резултат:** средното от резултатите на оценяваните стъпки; `shell.finish(ratio, onComplete, restart)`. 100% само без грешки. „Започни отначало“ връща всичко в начално състояние.
9. **Устройства:** работи с мишка и с пръст, на тесен екран (360 px) и на слаб компютър. Малко полигони, без тежки текстури, `shadows: true` само ако си струва.
10. **Без грешки в конзолата** и без мрежови заявки извън сайта.

## Проверка преди предаване

* Автоматичен тест в Playwright, който изиграва преживяването докрай: с една умишлена грешка и после правилно. Крайният резултат трябва да е правилен.
* Снимки на всяка стъпка, прегледани на око: нищо не е отрязано, етикетите се четат, балончетата не закриват задачата.
* Проверка на ширина 390 px.

## Статии като живи 3D сцени

Статия от раздела (`unit.article` в `data/gradeN.js`) с `quality: "high"` и `experience: "<име>"` се показва от `renderLiveArticle` в `js/app.js`, който зарежда `js/exp/<име>.js` и вика:

```js
export function mount(container, { article, course, onComplete }) {
  // article: { id, title, steps: [{ focus, text }], scene: { objects: [{ id, label, … }] } }
  return { dispose() { /* спира всичко */ } };
}
```

* **Четене, не упражнение:** без точки и без `stepScore`/`shell.finish`.
* Една стъпка = един елемент от `article.steps`. Камерата отива до обекта `focus` (id от `scene.objects`), текстът `steps[k].text` се показва **дословно** в широко балонче до обекта (`stage.bubble(…, { cls: 'wide' })`), заглавието на стъпката е `label` на обекта. Процесът за стъпката се оживява, а сцената продължава да се движи.
* Панелът има само брояч „k / n“ и бутони „← Назад“ / „Напред →“; на последната стъпка — „Готово ✔“.
* Текстът е или в балончето, или в `shell.task`, никога и на двете места — иначе гласът (`js/voice.js`) го чете два пъти. Кратки подсказки в панела се пишат без `shell.task`.
* „Готово ✔“ вика `onComplete()`: той отбелязва статията като прочетена и връща `{ back }` (адрес на курса). После се показва кратък екран „Прочете статията!“ с връзка към `back` и бутон „Прочети отначало“, който връща на стъпка 1.
* Образец: `stories4.js` (статиите за 4. клас; сцената се избира по `article.id`).

## Общи части за историята (`js/exp/hist/`)

| Модул | Функция | За какво е |
|---|---|---|
| `hist/map.js` | `await createMap(stage, { center, unitsPerDeg, focus })` | Жива карта от `data/geo/balkans.json` (Natural Earth, днешни граници). `pos(lon, lat)` дава точка в сцената; `addPlace(id, { lon, lat, label, labelDx })` слага карфица с `pickId`; `colorPlace`, `showPlace`, `highlight(countryId, color)`. Карфиците пулсират, морето „диша“. |
| `hist/timeline.js` | `createTimeline(stage, { from, to, z, length, tick, tickLabel })` | Линия на времето с ивици за векове. `addSlot(id, { year, label })` — гнездо (близките гнезда автоматично се редуват на два реда); `addCard(id, { label, x, z })` — карта за влачене (`dragId`); `slotAt(pos)`, `placeCard`, `sendHome`, `setCursor(year)` за плъзгач на годината, `reset()`. Помощни: `romanCentury(y)`, `yearFmt(y)`. |

Образец: `vladeteli.js` (3.2.2) — картата и линията заедно; плъзгач на годината сменя столицата; делата се влачат при владетелите.

**Еквивалентът на „опит“ в историята** е работа с извор: карта, документ, предмет. Стъпка „предскажи“ никога не измисля друга история: детето избира между реални възможности, а сцената показва какво наистина е станало.

**Карти:** `tools/make-geo.mjs` прави `data/geo/balkans.json` от world-atlas (Natural Earth). Историческите граници (1878, 1913, 1919, 1940, 1947) още не са налични; когато се добавят, всеки слой трябва да носи източник.

**Проверка:** `xp.html?exp=<име>` показва преживяването без курса. `tools/test-vladeteli.mjs` е образец за автоматичен тест (Playwright: `NODE_PATH=$(npm root -g) node tools/test-vladeteli.mjs http://localhost:8765/history/ <папка> [ширина]`).

## Подробна архитектура (`js/exp/hist/architecture.js`)

Известните сгради се правят оттук, не от прости кутии. Текстурите (мрамор, камък, варовик, кирпич, римска тухла, керемиди, пясък, скала) се рисуват в canvas, а геометриите и материалите се кешират (`M(color, { tex, rep })`).

| Функция | Какво прави |
|---|---|
| `column(order, { h, r })` | Дорийска, йонийска или коринтска колона: канелюри, ентазис, капител |
| `greekTemple({ w, d, h, front, side, order })` | Храм с периптер, цела, фриз с триглифи, фронтони със статуи, керемиден покрив (Партенон, Хефестейон, Ерехтейон) |
| `stoaDetailed`, `tholos`, `rockHill`, `statue` | Стоа, кръгла сграда, скален хълм с подпорна стена, бронзова статуя |
| `romanTheatre`, `amphitheatre`, `baths`, `archGeo` | Театър с кавея, диазома и двуетажна сцена; амфитеатър с аркади; терми с купол и пещ; истински арки |
| `basilica`, `crenellatedWall`, `towerDetailed`, `gableRoof`, `steps` | Базилика с три кораба и апсида; стени със зъбци; покриви; стилобат |
