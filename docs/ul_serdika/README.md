# ул. „Сердика“ 20 в 3D

Разходка пеша в радиус 200 м около ул. „Сердика“ 20 в центъра на София
(в OpenStreetMap това е сградата „Бивш хотел „Прентан““). Работи в браузъра,
без ключове и без регистрация.

## Откъде идват детайлите

Всичко на картата е построено от реалните данни на [OpenStreetMap](https://www.openstreetmap.org/copyright)
(© сътрудниците на OpenStreetMap, лиценз ODbL).

| Какво | Откъде | Бележка |
| --- | --- | --- |
| Очертания на сградите | OSM | точни |
| Височина | `building:levels`, `height`, `roof:*` | където липсват, височината е приблизителна и в прозорчето пише „≈ … (приблизително)“ |
| Части на сгради (минаре, куполи) | `building:part` | Баня баши джамия, Партийният дом |
| Улици, настилка, ширина | `highway`, `surface`, `lanes`, `width` | паветата на ул. „Сердика“ са от `surface=sett` |
| Трамвайни релси и контактна мрежа | `railway=tram` | стълбовете са поставени през ~35 м |
| Табели на магазини и офиси | имена от OSM (`shop`, `amenity`, `office`…) | на стената, най-близо до точката |
| Номера на сградите | `addr:street`, `addr:housenumber` | табелка на стената към улицата |
| Пешеходни пътеки, светофари | `highway=crossing`, `traffic_signals` | |
| Дървета, пейки, кошчета, контейнери, спирки | OSM | в парковете са добавени още дървета според площта |
| Улични лампи | OSM, а ако са малко — през ~26 м по улиците | |
| Паркирани коли | `parking:*` където го има, иначе случайно | не са истински |
| Витоша, Люлин, Стара планина | приблизителни посоки и височини | силует на хоризонта |
| Слънцето | изчислено за София за избрания час днес | |

Някои известни сгради имат ръчни поправки (купол на синагогата, височина на Халите
и на Минералната баня, цветове) — вижте `LANDMARKS` в `js/world.js`.

## Данните

Страницата първо чете `data/osm.json` (снимка на данните, записана до нея).
Ако файлът липсва, тя ги тегли направо от Overpass API и ги пази в браузъра за 30 дни.
Бутонът „Изтегли данните наново“ в настройките тегли от Overpass, без да гледа снимката.

За да обновите снимката (от папката `docs/ul_serdika`):

```bash
node tools/fetch-osm.mjs
```

## Управление

| Клавиш | Действие |
| --- | --- |
| W A S D / стрелки | ходене |
| мишка | оглеждане (щракнете в картината) |
| Shift | по-бързо |
| M | карта (щракване върху картата премества там) |
| H | обратно пред №20 |
| Esc | пауза |

На телефон: левият палец ходи, плъзгането вдясно оглежда.

## Файлове

| Файл | Какво прави |
| --- | --- |
| `index.html` | страница, стилове, интерфейс |
| `js/main.js` | сцена, небе, слънце, планини, управление, карта, надписи |
| `js/osm.js` | заявки към Overpass, превръщане в метри |
| `js/world.js` | сгради, покриви, улици, табели, дървета, лампи, коли |
| `js/textures.js` | всички текстури, нарисувани с код (фасади, павета, плочки, керемиди) |
| `js/three.module.min.js` | three.js r160 (MIT) |
| `data/osm.json` | снимка на данните от OSM |
| `tools/fetch-osm.mjs` | обновява снимката |
