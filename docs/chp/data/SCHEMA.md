# Схема на данните за курсовете

Всеки клас е един ES модул: `data/grade3.js`, `grade4.js`, `grade5.js`, `grade6.js`.
Модулът изнася по подразбиране един обект — курса.

```js
export default {
  id: "5",
  title: "Човекът и природата — 5. клас",
  source: {
    pdf: "up_v_chp.pdf",
    title: "Учебна програма по човекът и природата за V клас (МОН)"
  },
  units: [ /* точно 3 раздела */ ]
};
```

## Раздел (unit)

```js
{
  id: "5-1",
  title: "Физични явления",
  mon: { pages: [4, 5], part: "Част I. Физични явления" },  // null, ако разделът не идва от МОН
  assumption: null,      // текст, ако групирането е наше предположение → червен знак в сайта
  article: { /* по една статия на раздел, т.е. най-много 3 за курса */ },
  skills: [ /* умения */ ]
}
```

## Умение (skill)

```js
{
  id: "5.1.1",                    // клас.раздел.умение
  title: "Маса, обем и форма на телата",
  mon: {
    pages: [4],                   // страници в PDF файла на програмата
    topic: "1.1 Основни характеристики на телата и веществата",  // тема, както е в програмата
    competences: [                // очаквани резултати от програмата, почистени от
      "Сравнява твърди тела, течности и газове по свойства като маса, обем и форма.",
      "Измерва обем и маса на твърди тела и течности."
    ]
  },                              // mon: null → червен знак „Не е по програма на МОН“
  assumption: null,               // текст, ако нещо в умението е наше предположение
  quality: "low",                 // "low" = опростено 3D (червен знак „В разработка“), "high" = пълно преживяване
  experience: null,               // за "high": име на модула в js/exp/ (напр. "cell")
  video: null,                    // { youtubeId, title } — само проверено видео от Кан Академия; иначе null
  scene: { objects: [ /* обекти в 3D сцената */ ] },
  questions: [ /* 6–8 въпроса */ ]
}
```

### Обект в сцена

```js
{ id: "ice", label: "Лед", shape: "box", color: "#9fd8ff",
  pos: [-2, 0, 0], scale: 1, note: "Твърдо тяло: има собствена форма и обем." }
```

* `shape`: `box`, `sphere`, `cylinder`, `cone`, `torus`, `capsule`, `ring`, `plane`.
* `scale`: едно число или `[x, y, z]` за удължени и плоски тела.
* `pos`: координати в диапазона приблизително от −4 до 4 по x и z, от 0 до 3 по y.
* 3–7 обекта на сцена.
* `note`: кратък текст (до 140 знака), който се показва до обекта, когато ученикът кликне върху него.
  Това е „текстът на логичното място“.

### Въпроси

Всички въпроси имат `q` (текст) и `explain` (обяснение, показвано след отговора).

| type | Полета | Бележки |
|---|---|---|
| `mcq` | `choices: [..]`, `answer: 0` | един верен отговор |
| `multi` | `choices: [..]`, `answer: [0, 2]` | няколко верни |
| `sort` | `bins: ["А", "Б"]`, `items: [{ t: "…", bin: 0 }]` | 4–8 елемента |
| `order` | `items: ["първо", "второ", …]` | в правилния ред; сайтът ги разбърква |
| `number` | `answer: 12`, `tolerance: 0`, `unit: "cm"` | |
| `pick` | `answer: "objId"` | „Кликни върху…“ в 3D сцената; в тестовете става избор от етикетите |

## Статия (article)

```js
{
  id: "5-1-a",
  title: "Пътешествие в света на частиците",
  quality: "low",
  scene: { objects: [ /* както горе, като всеки обект има note */ ] },
  steps: [ { focus: "ice", text: "Абзац до 400 знака, закачен за обекта." } ]   // 3–6 стъпки
}
```

## Правила за съдържанието

* Пишете на правилен български, за съответната възраст (3. клас е 9-годишни деца).
* Въпросите проверяват очакваните резултати от `mon.competences`, а не странични факти.
* Фактите трябва да са научно верни. При съмнение по-добре пропуснете въпроса.
* Не измисляйте видеа, връзки или номера на страници.
