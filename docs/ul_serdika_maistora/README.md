# ул. „Сердика“ 20 по Майстора

Трета версия на [разходката около ул. „Сердика“ 20](../ul_serdika/): същите улици и
сгради от OpenStreetMap в радиус 200 м, нарисувани в духа на Владимир Димитров – Майстора.

| Какво | Как |
| --- | --- |
| Цветове | Чисти, ярки, плоски: жълто, червено, изумрудено, тюркоазено, розово |
| Контури | Плътни тъмни линии около всичко |
| Фасади | Шевици по етажите, прозорци с лале отгоре, сандъчета с мушката |
| Павета | Мозайка от плоски камъни с тъмни фуги |
| Трева и дървета | Цветя в тревата, ябълки по дърветата; листата сменят цвета си по сезоните |
| Небе | Плоски ивици от лимоненозелено до кобалт, кръгли облаци с контур, слънце с лъчи като венчелистчета |
| Нощ | Осмолъчни звезди като в шевиците, жълт полумесец, светнали прозорци и звезди-розетки около фенерите |

Кодът е общ с версията по Ван Гог: `../ul_serdika/js/art/`. Стилът се избира с
`<html data-style="maistora">`, а всичко, по което стиловете се различават, е в `style.js`.
Текстурите на Майстора са в `maistora.js`.

Превключвателят „Стил“ (на началния екран и в настройките) води към другите две версии,
като запазва мястото, посоката, часа и сезона.
